# Akshat Malik — Full Stack GenAI Engineer Portfolio

A modern, high-performance portfolio website built with **Next.js 15**, **TypeScript**, **Tailwind CSS**, and **Shadcn UI**.

## Features

- **Full Stack & GenAI Showcase:** Highlighted projects including Chat-Relay MCP, Multi-Agent RAG Research System, Resume Analyzer, and CodeSandbox.
- **Background Music Engine:** Synchronized studio audio playback with continuous 360° vinyl avatar rotation, smooth fade-in/fade-out, and Nothing OS dot-matrix typography.
- **Open Source Tracker:** Integrated GitHub contribution graphs and open-source pull request tracker.
- **Technical Blog:** MDX-powered technical writing system.
- **Glassmorphic Floating Navigation:** Dynamic Island navigation dock with smooth view transitions.

## Tech Stack

- **Framework:** Next.js 15 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS, Shadcn UI
- **Animations:** Custom CSS 360° rotation engine & IntersectionObserver ScrollReveal
- **Analytics:** Umami Privacy-Focused Web Analytics

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/akshatmalik-bruh/akshatmalik-bruh.github.io.git
   cd akshatmalik-bruh.github.io
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Run the development server:

   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.
